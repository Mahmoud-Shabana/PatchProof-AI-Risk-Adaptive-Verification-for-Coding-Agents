# Contributing

PatchProof AI is published primarily as a reproducible micro1 Frontier Engineering Challenge 2026 submission.

For review or research contributions:

1. Open an issue describing the proposed change and its evaluation rationale.
2. Preserve benchmark integrity; never tune hidden tests after observing model output.
3. Add or update deterministic tests for workflow changes.
4. Report negative results as well as positive ones.
5. Never commit credentials, private information, or local environment files.

All contributions must respect the project license, the applicable hackathon terms, and third-party licenses.
